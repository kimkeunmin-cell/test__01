🐍 Snake Game (HTML + CSS + JavaScript)
키보드 화살표 키로 조작하는 간단한 스네이크 게임입니다.
HTML 파일 하나에 CSS와 JavaScript가 모두 포함된 단일 파일 구조로 제작되었습니다.

📌 Features
HTML 하나로 실행되는 순수 프론트엔드 게임

Arrow Keys(↑ ↓ ← →)로 뱀 조작

랜덤 위치에 생성되는 먹이

먹이를 먹을 때마다 길어지는 스네이크

벽 충돌 및 자기 몸 충돌 시 Game Over

점수 표시 기능 포함

📂 File Structure
코드
/snake-game
 └── index.html   # 게임 전체가 포함된 단일 파일
🚀 How to Run
이 저장소를 다운로드하거나 클론합니다.

index.html 파일을 더블 클릭하여 브라우저에서 실행합니다.

방향키로 게임을 플레이합니다.

🎮 Controls
Key	Action
↑	위로 이동
↓	아래로 이동
←	왼쪽으로 이동
→	오른쪽으로 이동

🧩 Code Overview
<canvas> 요소를 사용해 게임 화면을 구성

setInterval()로 게임 루프 실행

뱀의 위치를 배열로 관리

음식은 랜덤 좌표로 생성

충돌 감지 후 게임 종료 처리
