# 🐍 Snake Game (HTML + CSS + JavaScript)

키보드 **화살표 키**로 조작하는 간단한 스네이크 게임입니다.  
HTML 파일 하나에 **CSS와 JavaScript가 모두 포함된 단일 파일 구조**로 제작되었습니다.

---

## 📌 Features

- HTML 하나로 실행되는 **순수 프론트엔드 게임**
- **Arrow Keys**(↑ ↓ ← →)로 뱀 조작
- 랜덤 위치에 생성되는 먹이
- 먹이를 먹을 때마다 길어지는 스네이크
- 벽 충돌 및 자기 몸 충돌 시 **Game Over**
- 점수 표시 기능 포함
